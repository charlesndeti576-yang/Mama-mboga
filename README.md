# 🥬 Mama Mboga

A simple, mobile-friendly fresh-produce business website designed for **Mama Mboga**, a vegetable seller based at **Machakos Main Market, Kenya**.

The website helps customers view available vegetables, check prices, and place orders directly through WhatsApp.

## 🌱 About the Business

**Mama Mboga** provides fresh vegetables for:

- 🏠 Household customers
- 🍽️ Restaurants and food vendors
- 🏪 Shops and resellers
- 📦 Bulk buyers

The website is designed to make ordering simple:

**Choose a product → Check the price → Place an order → Confirm through WhatsApp**

## 🛒 Products & Prices

| Product | Price |
|---|---:|
| 🍅 Tomatoes | KSh 100/kg |
| 🧅 Onions | KSh 80/kg |
| 🌶️ Chillies | KSh 120/kg |
| 🫑 Pilipili Hoho | KSh 80/kg |
| 🌿 Coriander | KSh 10/bundle |

> Note: Prices for tomatoes, onions, chillies, and pilipili hoho can be adjusted using the price-management buttons. Coriander remains fixed at KSh 10 per bundle.

## 📱 WhatsApp Ordering
